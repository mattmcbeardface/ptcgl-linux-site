About PTCGL-Linux

A little Linux glue for the official game.

PTCGL-Linux is not a replacement client, remake, or custom game. It runs the official Pokémon TCG Live app inside a managed Linux compatibility environment built around Proton.

It handles the prefix, required runtime pieces, installation, and browser login callback so the game can be launched from the Linux desktop like a normal application.

This is an independent, unofficial open-source project. It is not affiliated with, endorsed by, or sponsored by The Pokémon Company International.
