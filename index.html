So... what is this thing?

A little Linux glue for the official game.

PTCGL-Linux is not a replacement client, remake, or custom game. It wraps the official Pokémon TCG Live app in a managed Linux compatibility environment so you don't have to babysit Wine, Proton, prefixes, or login callbacks yourself.

The goal is simple: install it once, find Pokémon TCG Live in your app menu, and use it like a normal Linux application.
